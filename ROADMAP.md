# Roadmap

This roadmap represents more than 20 hours of planned development for the read-only SWERRV catalogue. Estimates are working time, not calendar time.

## Foundation and interaction — 6 hours

- [ ] Add keyboard-first navigation and visible focus states (2h)
- [x] Add accessible modal focus management and Escape-to-close behaviour (2h) — Escape-to-close is implemented; focus trapping remains planned.
- [ ] Add loading, missing-image, and reduced-motion states (2h)

## Editorial catalogue — 7 hours

- [ ] Create a typed/content-driven catalogue schema for future entries (2h)
- [ ] Add image metadata, captions, and responsive art direction (2h)
- [x] Build a sortable archive view with stable URL filters (3h)

## Visual system — 6 hours

- [ ] Refine typography scale and spacing tokens across breakpoints (2h)
- [ ] Add a print-friendly catalogue layout (2h)
- [ ] Add a dark/light presentation study without storing preferences (2h)

## Quality and release hygiene — 6 hours

- [ ] Add component tests for filters, previews, and empty states (2h)
- [ ] Add a production accessibility and responsive smoke-test checklist (2h)
- [ ] Add CI for install, lint, and build with no secrets or external services (2h)

## Documentation and content review — 4 hours

- [ ] Add contribution guidance for fictional/sample content only (1h)
- [ ] Review image licensing and document asset provenance (2h)
- [ ] Record a short release checklist and changelog format (1h)

Total planned work: **29 hours**.

The scope will remain non-transactional: no accounts, personal-data collection, payments, messaging, persistence, or external service integration is planned.
